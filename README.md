
# Python Banking System

## Project Description
A menu-driven banking application developed using
Object-Oriented Programming in Python.

## Features
- Create bank accounts
- Deposit money
- Withdraw money
- Check account balance
- View transaction history

## OOP Concepts Used
1. Classes and Objects
2. Constructors
3. Encapsulation
4. Inheritance
5. Polymorphism
6. Abstraction

## Technologies
- Python 3
- VS Code

## Execution
Run the following command:

python main.py
